# پروژه‌ها و قراردادها

برای هر پروژه یا قرارداد یک پرونده مستقل ایجاد شود. حداقل اطلاعات: عنوان، شناسه، محل، شرح کار، کارفرما/واحد متولی، پیمانکار، ناظر، مشاور، مبلغ، مدت، تاریخ‌های کلیدی، منبع اعتبار، وضعیت پیشرفت، آخرین اقدام و اسناد مرتبط.

تشریفات معامله و انعقاد قرارداد در صلاحیت واحدهای ذی‌ربط است؛ این بخش برای ثبت و پایش و پیگیری فنی است.
