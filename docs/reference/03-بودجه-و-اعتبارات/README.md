# بودجه و اعتبارات

در این بخش اسناد پژوهشی، پیشنهادهای بودجه، متمم‌ها، وضعیت مصوب و تخصیص‌یافته، تعهدات، پرداخت‌ها و گزارش‌های پایش اعتبار نگهداری می‌شود.

- [پژوهش ۰۲ ـ طرح پیشنهادی نظام برنامه‌ریزی، بودجه‌ریزی و پایش پروژه‌های فنی و عمرانی دفتر فنی](پژوهش-02-نظام-برنامه-ریزی-و-پایش-پروژه-های-فنی.md)

## قاعده ثبت
اعتبار مصوب، تخصیص‌یافته، تعهدشده، صورت‌وضعیت‌شده، تأییدشده، پرداخت‌شده و مانده در ستون‌های جداگانه ثبت شوند. اسناد مالی محرمانه فقط با رعایت سطح دسترسی سازمانی نگهداری شوند.

## وضعیت اسناد
اسناد پژوهشی تا زمان بررسی و تأیید مراجع ذی‌صلاح، صرفاً مرجع مطالعاتی و پیشنهاد کارشناسی هستند و نباید به‌عنوان دستورالعمل مصوب یا مجوز مالی تلقی شوند.
