# مکاتبات و اسناد

مکاتبات، صورت‌جلسات، نقشه‌ها، دستورکارها، گزارش‌های بازدید، مستندات فنی و پیوست‌های مرتبط در این بخش ثبت می‌شوند.

برای هر سند، تاریخ، شماره، فرستنده/گیرنده، موضوع، پروژه مرتبط، وضعیت اقدام، مسئول پیگیری و مسیر فایل درج شود. از بارگذاری اطلاعات شخصی یا اسناد محرمانه بدون مجوز و کنترل دسترسی خودداری شود.
